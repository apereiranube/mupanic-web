# MU PANIC Web

Sitio web oficial de MU PANIC.

Base técnica: WebEngine CMS 1.2.7, adaptado para Louis UP43 / Season 6 y la base MSSQL `MuOnline43`.

## Flujo
- `main`: estable / producción
- `beta`: desarrollo y pruebas en beta.mupanic.com.ar

## Seguridad
No subir credenciales, contraseñas SQL ni archivos de configuración con secretos al repositorio.
