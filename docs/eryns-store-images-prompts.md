# Imágenes y prompts de la tienda ERYNS

Las tres ilustraciones de paquetes se generaron con image_gen integrado, con transparencia real. El medallón de Eryns sirve como referencia común de identidad. Se integran como WEBP con alpha.

| Imagen | Archivo integrado | Uso |
| --- | --- | --- |
| Bolsa inicial | `img/recharge/eryns-pack-pouch.webp` | Packs iniciales; escala menor |
| Cofre | `img/recharge/eryns-pack-chest.webp` | Packs intermedios |
| Cofre legendario | `img/recharge/eryns-pack-legendary.webp` | Pack superior; más tamaño y brillo |
| Escena de Theryon | `img/recharge/eryns-legends-v3.webp` | Hero existente; no requiere nueva generación |
| Theryon, Nerathys y Vaeraxes | `img/atlas/vinculos/*-cinematic.webp` | Vitrina y ventanas de detalle existentes |

Los iconos de confianza siguen el sistema SVG de la web: no necesitan generación raster.
